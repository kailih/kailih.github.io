Research

CoGR: Co-Evolving Generative Retrieval

Two LLMs, one for queries and one for items, learn to write matching keyword representations. After SFT they are trained with alternating GRPO updates against a single shared retrieval objective, with a counterfactual marginal reward for item-level credit assignment. 10.9–36.1% relative F1 gains over the strongest baseline.

Autoresearch: an agent that runs the experiment loop

A generic workflow in which an LLM agent proposes, trains, evaluates, and accepts or rejects experiments on its own, inside rules a person sets. I built one instance of it for model compression; after manual validation of the first iterations, it ran a multi-day sequence of experiments without further input and delivered a materially smaller model within the performance tolerance.

ColBERT-Serve

A serving system that memory-maps the ColBERT index, uses a sparse first stage (SPLADEv2) to pick candidates, and re-ranks them with ColBERT under a hybrid score. Cuts RAM by 90% and lets late-interaction retrieval run on inexpensive servers under many concurrent queries. ECIR 2025, with Matei Zaharia (Databricks co-founder), Christopher Potts, et al.

Chinese Dialogue Corpora + DSTC9

Three widely used open datasets for Chinese dialogue (CrossWOZ, KdConv, LCCC), each shipped with benchmark models and, for CrossWOZ, a user simulator. Together they have 3,000+ GitHub stars. I also co-organized the DSTC9 multi-domain task-completion track built on them.

Structured Pruning for CLIP

Extended structured pruning to a multimodal dual-encoder for the first time, removing 40% of CLIP's parameters at a 1% accuracy cost. Built the sparse PyTorch training pipeline, decomposed Block Movement Pruning into modular steps, and added auxiliary losses to balance the two modalities.

LLM Evaluation & Alignment

Three threads from Microsoft AI. Rubric-based LLM-judge evaluation with human-in-the-loop metrics for Copilot's retrieval-augmented generation; post-training for multimodal retrieval models (Qwen-VL, CLIP-style); and an LLM teacher distilled into a lightweight E5 retriever that shipped after A/B testing.

Model-Based RL for Dialogue Policy

Built SLBO and vanilla policy-gradient agents for a movie-ticket booking task, a chatbot environment and user-simulator sampling pipeline to train them, and a harness for comparing model-based deep RL algorithms on dialogue policy. Stanford UGVR with Tengyu Ma.

Coursework

Engineering Effective In-Context Inputs for GPT-3 in OpenQA

Designed and evaluated novel in-context learning strategies to improve GPT-3’s performance on OpenQA without access to gold passages. Explored lexical, syntactic, and semantic similarity-based example selection methods, and introduced reverse ordering to enhance contextual relevance. The semantic similarity + reverse order strategy achieved the best performance (F1=0.57), yielding a 5% improvement over the random baseline. Findings highlight the impact of example amount, quality, similarity, and ordering on large language model effectiveness.

Optimizing Dialogue History Encoding for Multilingual Task-Oriented Systems

Proposed an efficient training strategy for multilingual virtual assistants by replacing natural language dialogue history with structured dialogue states. Built on the BiToD architecture to reduce reliance on weak natural language encoders and improve slot value extraction. The work investigated the impact of history length (number of previous turns) on model performance, identified diminishing returns, and explored few-shot learning for hard examples. It is designed to improve scalability and robustness in low-resource languages.

Which Trick Works Best in GNN?

In this blog, we reproduced the work of "Residual Network and Embedding Usage - New Tricks of Node Classification with Graph Convolutional Networks." and deliver a thorough introduction and analysis. In detail, we implemented the Graph Attention Network and several commonly used tricks to challenge the node classification task on the ogbn-arxiv dataset. Our experiments show satisfactory results on this dataset. At the same time, we explored the effectiveness of different tricks proposed or introduced in the paper. From our experiments, we found that Node2Vec embeddings, label usage, and C&S achieved noticeable improvements on the task while changing the network structure of GAT and leveraging self-KD barely increases the accuracy.
